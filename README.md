# SI Carton Tracker — Production Planning & Finished Goods WH

A lightweight web application for **Production Planning / Finished Goods Warehouse** operations.

The application is designed around carton-level tracking, finished-goods visibility, inbound input, dispatch/outbound history, and synchronization with operational spreadsheet data.

## Business Context

The project models a practical Finished Goods Warehouse workflow:

```
Input / Inbound
      ↓
Carton Tracking
      ↓
Finished Goods Stock
      ↓
Search & Monitoring
      ↓
Dispatch / OUT
      ↓
History & Reporting
      ↓
Spreadsheet Synchronization
```

## Key Capabilities

- Google authentication
- Manual carton input
- Automatic stock-data pull by SO
- Finished-goods / carton tracking
- SO and article grouping
- Carton number and size tracking
- Warehouse location and room tracking
- Destination tracking
- Active stock vs OUT/history views
- Search and date filtering
- Bulk selection and dispatch workflow
- Dispatch history
- Google Sheets synchronization
- Responsive mobile-first interface
- Light / dark mode
- Progressive loading / batch rendering for large history datasets

## Technology
